Trackly

Real-time friend location sharing app

Vanilla JS No backend Live map Room codes

01 About the Project

Trackly lets you see where your friends are in real time on a live map. You create a room, share a short code, pick a colour and name, and you show up as a pin on a shared map. That's it: no accounts, no app to download.

02 What I Built

Built with vanilla HTML, CSS and JavaScript. I used Leaflet.js for the map with tiles from OpenStreetMap. To share locations between users without a server I used the BroadcastChannel API, with LocalStorage as a fallback. Each person gets a colour-coded pin with their initials, and there's a bottom sheet that lists everyone in the room and how far away they are.

03 What I Learned

This was probably the most technically challenging thing I've built. I'd never used the Geolocation API or BroadcastChannel before so there was a lot of figuring things out as I went. I also had to think about how to keep it simple enough that someone could just use it without any explanation. No sign-up, just a code and you're in.
