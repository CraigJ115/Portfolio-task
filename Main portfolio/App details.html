Trackly

Real-time friend location sharing app

About the Project

Trackly is a browser-based app that lets you see where your friends are in real time on a live map. Users create or join a room using a short room code, pick a colour and name, and immediately appear as a pinned avatar on a shared map. No accounts, no installs — just share a code and go.

What I Built

The app is built entirely with vanilla HTML, CSS and JavaScript — no frameworks or libraries. The map is rendered using HTML5 Canvas, pulling tiles from OpenStreetMap, with custom pan, zoom and touch controls written from scratch. Friend locations are shared in real time using the BroadcastChannel API with LocalStorage as a fallback, so it works across tabs without needing a server. Each user gets a colour-coded avatar pin with their initials, and a bottom sheet shows all friends in the room along with their distance from you.

What I Learned

This project pushed me into areas I hadn't explored before — working directly with the Geolocation API, rendering a full interactive map on Canvas, and building peer communication without a backend using BroadcastChannel. It gave me a much stronger understanding of how browser APIs work under the hood and how to build something genuinely functional with just vanilla JavaScript.
