Trackly

Real-time friend location sharing app

About the Project

Trackly is a browser-based app that lets you see where your friends are in real time on a live map. Users create or join a room using a short room code, pick a colour and name, and immediately appear as a pinned avatar on a shared map. No accounts, no installs — just share a code and go.

What I Built

The app is built with vanilla HTML, CSS and JavaScript using Leaflet.js for the map, pulling tiles from OpenStreetMap. Friend locations are shared in real time using the BroadcastChannel API with LocalStorage as a fallback, so it works across tabs without needing a server. Each user gets a colour-coded avatar pin with their initials, and a bottom sheet shows all friends in the room along with their distance from you.

What I Learned

This project pushed me into unfamiliar territory technically, but also made me think carefully about UX decisions — designing an onboarding flow with zero friction (no sign-up, just a name, a colour and a code), and making the map UI legible at a glance with colour-coded avatar pins and a clear friend list. Getting that balance between simplicity and functionality right was the biggest design challenge.
